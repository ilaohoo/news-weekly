习近平在内蒙古乌兰察布考察

未来网 阅读原文 →
📚 知识拓展

乌兰察布位于内蒙古中部，是连接华北与西北的重要枢纽。这里风能、太阳能资源富集，被称为“空中三峡”，近年来大力发展新能源产业。同时，乌兰察布也是京津冀地区的重要生态屏障，承担着防沙治沙、水源涵养等功能。领导人考察通常聚焦区域发展战略，如“西电东送”“东数西算”等国家工程，以及乡村振兴、民族团结等议题。

📜 历史纵深

内蒙古自治区成立于1947年，是我国最早成立的民族自治区。乌兰察布在历史上是草原丝绸之路的重要节点，近代以来因生态脆弱而面临荒漠化威胁。国家自20世纪末启动退耕还林还草、京津风沙源治理等工程，乌兰察布的生态状况逐步改善。此次考察延续了国家对边疆地区发展与生态保护并重的治理思路。

🌐 全球对比

全球范围内，干旱半干旱地区的生态治理是共同难题。以色列通过滴灌技术实现沙漠农业，非洲“绿色长城”计划致力于防治荒漠化。中国在库布其沙漠治理、塞罕坝林场建设等方面积累了经验，并通过“一带一路”分享治沙技术。乌兰察布的探索既服务于国内碳中和目标，也为全球生态治理提供参考。

💭 思辨启发

领导人考察地方，往往释放政策信号。我们可以思考：为什么选择乌兰察布？是关注新能源布局，还是强调生态安全？或者两者兼有？此外，区域发展如何平衡经济增长与环境保护？当地牧民如何参与并受益于绿色产业？这些问题没有标准答案，但能帮助我们理解国家治理的复杂性。

习近平主席向广交会致贺信传递高水平开放强音

未来网 阅读原文 →
📚 知识拓展

广交会全称中国进出口商品交易会，创办于1957年，每年春秋两季在广州举办，是中国历史最悠久、规模最大的综合性国际贸易盛会。第140届广交会恰逢其创办65周年，展示中国制造向“智造”转型的成果。贺信通常强调开放合作、互利共赢，释放中国坚持全球化、扩大进口的信号。

📜 历史纵深

广交会诞生于西方对华封锁时期，最初旨在打破贸易禁运、换取外汇。改革开放后，广交会成为中国企业走向世界的窗口。加入WTO后，广交会规模迅速扩大，从线下延伸到线上。近年来，广交会增设进口展区，从“卖全球”转向“买全球”，见证了中国从贸易大国迈向贸易强国的历程。

🌐 全球对比

世界知名展会如德国汉诺威工业博览会、美国拉斯维加斯消费电子展（CES）等，均以展示前沿技术、促进贸易投资为目标。广交会与它们相比，更侧重日用消费品和中小企业对接。在全球贸易保护主义抬头的背景下，广交会坚持开放，为各国企业提供市场机遇，体现了中国维护多边贸易体系的立场。

💭 思辨启发

有人认为，线上展会兴起后，线下广交会的必要性下降。但线下面对面交流能建立信任、促成复杂交易，这是数字技术难以完全替代的。此外，广交会如何平衡“出口”与“进口”？如何帮助中小企业融入全球供应链？这些角度值得深入探讨。

于都河记得：一块门板“浮桥”到“长虹”的长征跨越

未来网 阅读原文 →
📚 知识拓展

于都河位于江西省于都县，是中央红军长征的出发地。1934年10月，中央红军主力8.6万余人在于都河畔集结，当地百姓用门板、床板等搭建浮桥，帮助红军渡河。如今，于都河上已建起多座现代化大桥，成为当地交通命脉。这个故事常被用来讲述军民鱼水情和长征精神。

📜 历史纵深

长征是人类历史上的伟大壮举，中央红军从于都出发，历时一年，途经14个省，翻越18座大山，跨过24条大河，最终抵达陕北。于都作为长征起点，承载着深厚的红色记忆。近年来，国家大力支持革命老区发展，于都的交通、产业、民生得到显著改善，门板浮桥变为长虹大桥，正是历史变迁的缩影。

🌐 全球对比

世界上许多国家都有纪念重大历史事件的遗址，如美国独立战争遗址、法国诺曼底登陆海滩等。它们通过保护遗址、发展红色旅游来传承精神。中国长征沿线也在推进“长征国家文化公园”建设，将文物保护、教育研学与乡村振兴结合，这种大规模线性文化遗产保护模式具有中国特色。

💭 思辨启发

从门板浮桥到现代化大桥，变化的是基础设施，不变的是奋斗精神。我们可以思考：红色遗址的保护与开发如何平衡？旅游开发会不会冲淡历史庄严感？年轻人如何通过实地走访真正理解长征精神，而不是停留在口号？

全国秋粮收获进入高峰期 进度过六成

未来网 阅读原文 →
📚 知识拓展

秋粮指秋季收获的粮食作物，主要包括水稻、玉米、大豆等，占全年粮食产量的四分之三左右。秋粮收获进度过六成，意味着全国大部分地区的秋收工作正有序推进。国家近年来大力推进高标准农田建设、推广良种良法，并运用卫星遥感、无人机等技术监测作物长势和灾情，保障粮食稳产增产。

📜 历史纵深

中国历史上长期面临粮食短缺问题，直到20世纪80年代家庭联产承包责任制推行后，粮食产量才大幅提升。2006年取消农业税，进一步减轻农民负担。近年来，国家实施“藏粮于地、藏粮于技”战略，粮食产量连续多年稳定在1.3万亿斤以上。秋粮丰收对保障国家粮食安全至关重要。

🌐 全球对比

全球粮食安全形势严峻，受气候变化、地缘冲突影响，部分国家面临饥荒风险。中国以占世界9%的耕地养活世界近20%的人口，粮食自给率保持在95%以上。与美国、巴西等农业大国相比，中国人均耕地少，更依赖精耕细作和科技投入。中国的粮食安全策略为发展中国家提供了借鉴。

💭 思辨启发

粮食丰收固然可喜，但也要看到挑战：耕地减少、水资源短缺、极端天气频发。我们如何在不破坏环境的前提下持续提高产量？转基因技术该不该推广？节约粮食除了“光盘行动”，还能做什么？这些问题需要理性讨论。

地缘冲突消息刺激 国际油价16日显著上涨

中国青年网 阅读原文 →
📚 知识拓展

国际油价受地缘政治影响显著。中东地区是全球最重要的石油产区，任何冲突升级都可能威胁原油生产和运输通道（如霍尔木兹海峡）。油价上涨会推高运输和化工成本，进而影响全球通胀。中国是石油进口大国，油价波动对国内经济有直接影响，因此国家建立了战略石油储备并推动能源多元化。

📜 历史纵深

1973年第四次中东战争引发石油危机，油价暴涨导致全球经济衰退。此后，地缘冲突与油价波动多次联动，如1990年海湾战争、2022年俄乌冲突。历史表明，石油不仅是商品，更是战略武器。中国自1993年成为石油净进口国以来，逐步建立战略储备体系，并大力发展新能源以降低对外依存度。

🌐 全球对比

美国通过页岩油革命实现能源基本自给，对中东石油依赖降低；欧盟积极推动可再生能源，但短期内仍依赖化石能源。中国则采取“多元进口+战略储备+新能源”的组合策略。各国应对油价波动的能力不同，但都认识到能源安全的重要性。

💭 思辨启发

油价上涨对普通人的生活有什么影响？除了加油变贵，还会导致物流成本上升、塑料制品涨价等连锁反应。另一方面，高油价会刺激新能源发展，这是不是一种倒逼机制？我们该如何看待能源安全与环境保护的关系？

国际能源署：全球柴油供应紧张将持续至2027年

中国青年网 阅读原文 →
📚 知识拓展

柴油是重要的工业燃料和运输燃料，广泛用于卡车、船舶、农业机械和发电。全球柴油供应紧张，主要原因是炼油产能不足、需求复苏以及地缘冲突导致的贸易流改变。柴油短缺会推高物流成本，影响农业和工业生产。国际能源署（IEA）是经济合作与发展组织框架下的政府间能源机构，其报告对市场有重要影响。

📜 历史纵深

炼油行业长期面临投资不足问题，发达国家对新建炼油厂的环境审批严格，导致产能增长缓慢。2020年疫情后，部分炼油厂关闭或转型生物燃料。俄乌冲突后，欧洲减少从俄罗斯进口柴油，转向其他地区，加剧了全球柴油贸易紧张。这种结构性矛盾短期内难以解决。

🌐 全球对比

各国应对柴油紧张的措施不同：美国释放战略储备并呼吁增加炼油产能；欧洲加速电气化以减少对柴油的依赖；中国则通过“减油增化”调整炼油结构，同时推广新能源汽车。全球能源转型过程中，传统能源供应的稳定性面临考验。

💭 思辨启发

柴油紧张背后是能源转型的阵痛。我们是否应该放缓新能源步伐以保障传统能源供应？还是应该加速转型以摆脱化石能源依赖？另外，柴油短缺对农民和卡车司机的影响最大，政策如何兼顾公平？

未来网 阅读原文 →
📚 知识拓展

浮空器是一种依靠空气浮力升空的飞行器，包括气球、飞艇等。与卫星相比，浮空器成本低、可长时间驻留空中，适合用于通信中继、环境监测、灾害预警等领域。“云哨M1000-CNS”能在全天候条件下工作，意味着它能在恶劣天气中执行任务，技术难度较高。

📜 历史纵深

浮空器历史悠久，18世纪法国孟戈菲兄弟发明热气球，20世纪初飞艇曾用于跨洋飞行。二战后，飞机和卫星的崛起使浮空器一度边缘化。近年来，随着材料科学和自动控制技术进步，平流层浮空器重新受到重视。中国在浮空器领域起步较晚，但进展迅速，已应用于应急通信和科研探测。

🌐 全球对比

美国、欧洲在平流层飞艇和系留气球方面有长期研究，如美国国防部的“综合传感器即是结构”项目。以色列在预警浮空器方面经验丰富。中国后来居上，在续航时间、载荷能力等方面取得突破。浮空器与卫星、无人机形成互补，构建空天地一体化网络。

💭 思辨启发

浮空器能飞很久，但受风影响大，如何保持稳定驻留？它的应用场景有哪些？比如在地震后通信中断时，浮空器可快速恢复信号。但浮空器也可能被用于军事侦察，技术是中性的，关键在于如何使用。

📚 知识拓展

钦州港位于广西南部，是北部湾港的重要组成部分，也是西部陆海新通道的关键节点。“无人码头”指通过自动化、智能化技术实现集装箱装卸、运输、堆存全流程无人作业。关键技术包括自动导引车（AGV）、智能调度系统、远程控制岸桥等。这大幅提高了效率，降低了人力成本和安全风险。

📜 历史纵深

🌐 全球对比

全球自动化码头主要集中在发达国家，但中国已成为自动化码头数量最多的国家。与国外相比，中国方案更注重系统集成和成本控制。钦州港作为后发港口，直接采用最新技术，避免了传统码头的改造难题。自动化码头也带来就业结构变化，需要更多技术维护人员。

本期话题：长征精神如何走进少年心里
党史研究专家

长征精神的核心是坚定理想信念、不怕牺牲、独立自主、顾全大局。对中学生讲长征，不能只停留在“爬雪山过草地”的故事层面，而要讲清楚：当时红军平均年龄不到20岁，很多战士就是今天的“同龄人”。他们面临的是生死抉择，而今天的少年面临的是成长选择。长征精神走进少年心里，关键在于找到“共鸣点”——比如面对困难时的坚持、团队合作中的担当。纪念长征胜利90周年，各地开展“少年接力新长征”活动，就是把历史叙事转化为当代少年的行动叙事。让少年明白：每一代人都有自己的“长征路”，走好脚下的路，就是对历史最好的致敬。

中学德育教师

在校园里，长征精神不能靠灌输，要靠体验。我们学校组织过“重走长征路”研学，学生用一天时间徒步20公里，途中设置“遵义会议”“飞夺泸定桥”等情境任务。走完之后，很多学生说“脚疼，但心里有劲”。德育的难点在于把宏大叙事转化为个体感受。队前教育、入队仪式、红色研学，都是很好的载体。但要注意避免形式化——戴红领巾不只是仪式，更要理解红领巾代表的责任。我建议把长征精神与日常行为规范结合，比如班级公约里的“不抛弃不放弃”，运动会上为最后一名鼓掌。精神落地，才是真正的传承。

青少年心理研究者

从心理发展角度看，12—18岁是自我认同形成的关键期。长征精神中的“理想信念”恰好回应了青少年“我是谁、我要成为什么样的人”的追问。但要注意，当代青少年面临的压力与长征年代不同，更多是学业竞争、网络信息过载、意义感缺失。长征故事中的“目标感”和“韧性”可以转化为心理资源。比如“四渡赤水”体现灵活应变，“半条被子”体现共情与分享。教育者可以引导少年把长征精神拆解为可操作的心理品质：遇到难题不轻易放弃、在团队中主动承担、对他人保持善意。这些品质一旦内化，比任何说教都更有力量。

本期话题：AI进校园，利大还是弊大
观点 A AI进校园利大于弊。首先，AI可以实现个性化学习，根据每个学生的薄弱点推送练习，让“因材施教”真正落地。其次，AI能解放教师的生产力，自动批改作业、生成学情报告，让老师有更多时间关注学生的情感和思维发展。再次，AI本身就是未来社会的必备素养，早接触早适应。甘肃高台“AI赋能智慧育人”的实践表明，AI不是替代老师，而是辅助老师看见每一个学生。当然，需要规范使用边界，但不能因为存在风险就拒绝工具。就像计算器进课堂，最终教会了学生更高效的运算方式。
观点 B AI进校园弊大于利。中学生正处于思维发展和价值观形成的关键期，过度依赖AI会削弱独立思考能力。写作靠AI生成、解题靠AI搜索，长此以往，学生可能失去“挣扎着思考”的耐心和韧性。其次，AI生成内容存在偏见和错误，中学生辨别能力有限，容易被误导。再次，AI收集大量学生数据，隐私保护是隐患。更值得警惕的是，教育不只是知识传递，更是人与人之间的情感交流、价值引导。AI可以批改作业，但无法替代老师的一个眼神、一句鼓励。在基础教育阶段，谨慎比激进更重要。
🤔 AI 的立场 双方都有成立的前提。A方成立的前提是：AI作为工具被规范使用，有明确的边界和教师的引导，且学生具备一定的信息素养。B方成立的前提是：AI被滥用或过度依赖，缺乏有效的监管和教学设计。问题的关键不在于“要不要AI”，而在于“怎样用AI”。对中学生而言，AI可以成为学习助手，但不能成为思考的替身。学校需要建立使用规范，比如哪些作业允许AI辅助、哪些必须独立完成；同时加强AI素养教育，让学生理解AI的能力与局限。技术本身无善恶，教育的智慧在于让技术服务于人的成长，而不是让人被技术牵着走。
