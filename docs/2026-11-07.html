习近平：践行全过程人民民主 确保选出人民满意的代表

未来网 阅读原文 →
📚 知识拓展

全过程人民民主是中国特色社会主义民主政治的鲜明特征，强调民主选举、民主协商、民主决策、民主管理、民主监督各环节环环相扣。人大代表换届选举是公民依法行使选举权的重要实践，县乡两级人大代表由选民直接选举产生，代表候选人要与选民见面、回答提问，选举结果须代表人民利益。这一制度设计旨在保证人民当家作主，让国家权力真正掌握在人民手中。

📜 历史纵深

1953年新中国颁布第一部选举法，确立普选原则；1954年第一届全国人民代表大会召开，人民代表大会制度正式建立。此后选举制度不断调整完善，1979年将直接选举扩大到县一级，2010年选举法修改实现城乡按相同人口比例选举代表。每一次修法都折射出国家治理理念的进步，也让“人民代表人民选”从口号变为可操作的制度安排。

🌐 全球对比

各国选举制度差异显著：美国实行选举人团间接选举总统，选民实际投票与最终结果可能不一致；英国下议院选举采用“简单多数制”，小党难以获得相应席位；一些国家投票率长期低迷。中国的人大代表选举强调广泛性和代表性，尤其注重基层一线代表比例。不同制度各有其历史土壤，比较时应关注制度是否真正服务于本国人民的根本利益。

💭 思辨启发

有同学可能会问：人大代表选举和我有什么关系？其实，从社区环境改善到学校周边交通治理，许多具体问题正是通过代表反映到决策层面的。可以思考：民主是否只有“投票”一种形式？协商、听证、基层议事会是不是民主的体现？评价一种民主制度，应该看形式还是看实效？这些问题的答案不是唯一的，但都值得认真讨论。

📚 知识拓展

“命运共同体”是中国外交的重要理念，强调各国在追求自身发展时兼顾他国合理关切，在谋求本国发展中促进共同发展。中国与非洲国家合作坚持“真实亲诚”理念和正确义利观，不附加政治条件，注重基础设施、农业、教育、医疗等民生领域。加蓬是非洲重要国家，森林覆盖率高，中加合作涉及林业、矿业、基础设施建设等多个领域，此次关系定位提升意味着双方合作将更加全面深入。

📜 历史纵深

中非友好交往源远流长。1956年中国与埃及建交，开启中非关系新篇章；20世纪60年代坦赞铁路成为中国援非的标志性工程；2000年中非合作论坛成立，中非合作进入机制化阶段。2013年提出“真实亲诚”对非政策理念，2018年中非合作论坛北京峰会提出“八大行动”，2021年提出“九项工程”。中非关系在相互尊重基础上不断升级，成为南南合作的典范。

🌐 全球对比

西方国家对非援助往往附带政治条件和经济改革要求，有时被批评为“新殖民主义”。中国对非合作强调不干涉内政、平等互利，援建项目侧重基础设施和民生改善。近年来欧盟、日本、印度等也加强对非合作，非洲成为大国关注的重点区域。不同合作模式各有特点，非洲国家也在自主选择合作伙伴，追求利益最大化。理解中非关系，需要放在全球南南合作的大背景下观察。

💭 思辨启发

有人问：中国为什么要花大力气帮助非洲国家？从经济角度看，非洲是重要的资源和市场；从政治角度看，发展中国家是国际格局中的重要力量；从道义角度看，共同发展符合人类整体利益。但也要思考：合作中如何避免债务风险？如何确保项目真正惠及普通民众？如何平衡各方利益？这些问题没有简单答案，却是理解国际关系的钥匙。

治理黄河80年取得举世瞩目伟大成就

未来网 阅读原文 →
📚 知识拓展

黄河是中华民族的母亲河，也是世界上泥沙含量最高、治理难度最大的河流之一。黄河治理的核心问题包括防洪、减沙、水资源调配和生态保护。新中国成立后，通过修建水库、加固堤防、水土保持、调水调沙等综合措施，黄河实现了伏秋大汛不决口的历史性转变。近年来，黄河流域生态保护和高质量发展上升为国家战略，治理理念从“征服自然”转向“人水和谐”。

📜 历史纵深

黄河历史上灾害频发，据记载两千多年间决口泛滥达1500多次，大改道26次。1938年花园口决堤造成巨大灾难。1952年毛泽东视察黄河提出“要把黄河的事情办好”。1957年三门峡水利枢纽开工，此后小浪底水利枢纽于2001年建成，成为黄河治理的关键工程。80年治理历程，见证了中国从传统治水向现代流域管理的转变。

🌐 全球对比

世界大河流域治理各有经验：美国田纳西河流域通过综合治理实现防洪、发电、航运多目标开发；埃及尼罗河阿斯旺大坝在防洪灌溉同时带来泥沙淤积和生态问题；欧洲莱茵河通过跨国协作治理污染。黄河治理的复杂性在于水少沙多、水沙关系不协调，中国探索的调水调沙等经验具有世界意义，也为其他多泥沙河流治理提供了参考。

💭 思辨启发

黄河治理取得了巨大成就，但是否意味着问题全部解决？黄河水资源仍然紧张，生态脆弱，下游“地上悬河”风险依然存在。可以思考：经济发展与生态保护如何平衡？上游用水与下游用水如何协调？治理黄河是政府的事，普通人能做什么？从节约用水到垃圾分类，每个人的选择都与河流健康有关。

开源开放 共建共享——2026年世界互联网大会乌镇峰会综述

未来网 阅读原文 →
📚 知识拓展

世界互联网大会乌镇峰会自2014年起每年举办，是中国主办的全球互联网领域重要盛会。峰会聚焦网络空间治理、数字经济发展、网络安全等议题，搭建了国际交流合作平台。2026年峰会强调“开源开放、共建共享”，反映全球互联网发展新趋势：开源技术降低创新门槛，开放合作促进数字红利共享。峰会还展示了智能互联网、人工智能应用等前沿成果。

📜 历史纵深

互联网1994年全功能接入中国，此后中国互联网产业快速发展。2014年首届世界互联网大会在乌镇举办，习近平主席提出“尊重网络主权、维护和平安全、促进开放合作、构建良好秩序”四项原则。2015年提出“构建网络空间命运共同体”理念。从学习引进到参与引领，中国在全球互联网治理中的角色不断变化，乌镇峰会成为观察这一变化的窗口。

🌐 全球对比

全球互联网治理存在不同模式：美国主张“多利益相关方”模式，强调企业和社会组织作用；欧盟注重数据保护和数字主权，出台《通用数据保护条例》；中国强调网络主权和 multilateral 治理。各国在跨境数据流动、人工智能治理、网络安全等议题上既有合作也有分歧。乌镇峰会提供了对话平台，推动形成更加公正合理的全球互联网治理体系。

💭 思辨启发

互联网让世界互联互通，但也带来数字鸿沟、数据安全、网络霸凌等问题。开源开放意味着技术共享，但如何保护知识产权？共建共享需要各国合作，但各国利益不同如何协调？作为数字原住民，青少年既是互联网的使用者，也是未来治理的参与者。可以思考：我们在享受网络便利时，是否意识到自己的数字权利和责任？

从两场外交活动，看中欧互利共赢之道

未来网 阅读原文 →
📚 知识拓展

中欧关系是世界上最主要的经济伙伴关系之一。欧盟是中国重要贸易伙伴，中国是欧盟最大进口来源地之一。中欧合作涵盖贸易、投资、科技、气候变化、人文交流等领域。中欧之间存在竞争，但合作面大于竞争面。两场外交活动可能涉及中欧高层对话和经贸磋商，体现双方在复杂国际形势下寻求互利共赢的努力。理解中欧关系，需要看到双方在经济上的互补性和在全球治理上的共同责任。

📜 历史纵深

1975年中国与欧洲经济共同体建立正式关系；2003年中欧建立全面战略伙伴关系；2014年习近平主席访问欧盟总部，提出中欧和平、增长、改革、文明四大伙伴关系。2020年中欧完成投资协定谈判（后因政治因素搁置）。中欧关系历经风雨，但对话合作始终是主线。近年来双方在气候变化、伊朗核问题等多边议题上保持沟通协调。

🌐 全球对比

欧盟与美国是传统盟友，但近年来在贸易、防务等问题上分歧增多；欧盟对华政策强调“伙伴、竞争者、制度性对手”三重定位。中国则强调中欧是合作伙伴而非对手。在全球格局深刻调整背景下，欧洲寻求战略自主，中国推动构建新型国际关系。中欧关系的走向对世界多极化进程有重要影响，双方如何在竞争中合作、在分歧中对话，是国际社会关注的焦点。

💭 思辨启发

中欧关系既有合作也有摩擦，比如在电动汽车、光伏产品等领域的贸易争端。可以思考：国家之间出现分歧时，对抗和对话哪种方式更有效？经济相互依存是促进和平的因素还是冲突的来源？作为消费者，我们购买欧洲商品或中国出口产品时，是否意识到背后复杂的国际分工？理解中欧关系，有助于我们以更成熟的眼光看待世界。

一条铁路 三座“全球第一”

未来网 阅读原文 →
📚 知识拓展

这条铁路可能指中老铁路或雅万高铁等中国参与建设的国际铁路项目，报道强调其在工程技术上创造的多项“全球第一”。中国高铁技术经过引进消化吸收再创新，已形成自主知识产权体系，在复杂地质条件、长大隧道、高速运行等方面积累了丰富经验。铁路“走出去”不仅是工程输出，也带动标准、装备、运营管理等方面的国际合作，是“一带一路”设施联通的重要组成部分。

📜 历史纵深

中国铁路建设经历了从追赶到领跑的过程。2008年京津城际铁路开通，中国进入高铁时代；2017年“复兴号”动车组投入运营，实现完全自主知识产权；截至2025年，中国高铁运营里程超过4.8万公里，居世界第一。中老铁路2021年通车，雅万高铁2023年开通，中国铁路技术在国际市场上展现出竞争力。三座“全球第一”是这一进程的最新注脚。

🌐 全球对比

日本新干线1964年开通，是世界首条高速铁路，长期保持技术领先；法国TGV、德国ICE也是欧洲高铁代表。中国高铁起步晚但发展快，在建设规模和运营经验上形成优势。在海外市场，中日高铁企业存在竞争，各自提供融资、技术、运营等方案。铁路合作不仅是商业行为，也涉及地缘政治和标准制定权，各国在选择合作伙伴时会综合考虑多方面因素。

💭 思辨启发

中国高铁“走出去”令人自豪，但也要看到挑战：海外项目面临政治风险、文化差异、标准对接等难题，部分项目盈利周期长。可以思考：技术领先是否等于市场成功？基础设施建设如何真正惠及当地民众？在赞美成就的同时保持理性，是成熟国民心态的体现。作为未来建设者，我们能为中国技术走向世界做哪些准备？

弘扬科学家精神·大家小事丨于敏：纸带上揪出的故障

未来网 阅读原文 →
📚 知识拓展

于敏是中国著名核物理学家，“两弹一星”功勋奖章获得者，被誉为“中国氢弹之父”。他长期从事核武器理论研究，在氢弹原理突破中发挥了关键作用。报道讲述的“纸带上揪出故障”故事，反映了他严谨细致、一丝不苟的科学态度。在计算机尚不发达的年代，科研人员通过分析纸带上的数据发现异常，这种对细节的敏感和执着，是科学家精神的具体体现。

📜 历史纵深

20世纪50年代，面对核威胁，中国决定自主研制核武器。1964年原子弹爆炸成功，1967年氢弹试验成功，从原子弹到氢弹仅用2年8个月，速度世界罕见。于敏当时隐姓埋名，长期在艰苦条件下工作，直到1988年身份才解密。他的故事是那一代科学家“干惊天动地事，做隐姓埋名人”的缩影，也是中国科技自立自强历程中的重要篇章。

🌐 全球对比

各国核武器研制历程中，科学家都发挥了关键作用。美国“曼哈顿计划”汇集了奥本海默、费米等顶尖科学家；苏联在库尔恰托夫领导下研制原子弹。不同国家科研体制各有特点，但科学家精神有共通之处：求真务实、勇于创新、甘于奉献。于敏的故事让世界看到，中国科学家在资源有限条件下凭借智慧和毅力取得突破，这种精神具有超越国界的感染力。

💭 思辨启发

于敏的故事让人感动，但也可以思考：在当今科研条件下，我们还需要“纸带上揪故障”那样的手工精神吗？人工智能和大数据能否替代科学家的直觉和判断？科学精神的核心是什么——是知识、方法，还是态度？对于中学生来说，认真对待每一道错题、每一次实验数据，或许就是科学家精神的萌芽。

走进低轨卫星研制团队，感受航天科技自立自强 未来中国的星空将进入“群星璀璨时”

未来网 阅读原文 →
📚 知识拓展

低轨卫星指运行在距地面约200至2000公里轨道上的卫星，具有传输时延低、信号损耗小等优势，广泛应用于通信、导航、遥感等领域。低轨卫星星座（如“星链”）通过大量卫星组网实现全球覆盖，是当前航天竞争的热点。中国正在推进自己的低轨卫星互联网建设，涉及卫星制造、火箭发射、地面终端等多个环节。报道走进研制团队，展现了中国航天科技自立自强的努力。

📜 历史纵深

中国航天事业起步于1956年，1970年“东方红一号”卫星发射成功。此后从返回式卫星到通信卫星，从北斗导航到载人航天，中国航天逐步建立起完整体系。近年来商业航天兴起，低轨卫星星座成为新赛道。2020年国家发改委将卫星互联网纳入“新基建”范畴，多个低轨星座计划相继启动。从跟跑到并跑，中国航天正在部分领域向领跑迈进。

🌐 全球对比

美国SpaceX公司的“星链”计划已发射数千颗低轨卫星，率先形成规模组网能力；英国OneWeb、亚马逊“柯伊伯”计划也在推进。低轨轨道和频率资源具有稀缺性，国际电信联盟规定“先占先得”，各国竞争激烈。中国低轨卫星发展面临发射成本、卫星批量制造、频率协调等挑战，但也拥有庞大的市场需求和应用场景优势。太空领域的竞争与合作，是未来国际关系的重要维度。

💭 思辨启发

低轨卫星竞争让人联想到“太空圈地运动”。轨道资源有限，先到先得是否公平？太空垃圾增多，谁来负责清理？卫星互联网让偏远地区也能上网，但会不会加剧数字鸿沟？科技发展总是伴随伦理和治理问题。作为未来公民，我们不仅要为技术进步欢呼，也要思考如何让科技发展更有序、更公平。

“中原”与“突突”，金寨县革命博物馆讲解词里的战地女婴

未来网 阅读原文 →
📚 知识拓展

金寨县位于安徽省西部，是著名的革命老区，被誉为“红军的摇篮、将军的故乡”。革命战争年代，金寨有十万儿女参军参战，许多人为革命牺牲。博物馆讲解词中的“中原”与“突突”是两个战地女婴的名字，背后是一段战争年代军民鱼水情的故事。这类革命文物和口述历史，是传承红色基因的重要载体，让历史从抽象的数字变成有温度的生命故事。

📜 历史纵深

金寨是鄂豫皖革命根据地的重要组成部分。1929年立夏节起义在这里爆发，红四方面军、红二十五军等主力部队先后在此组建。抗日战争和解放战争时期，金寨人民继续支持革命。新中国成立后，金寨被列为革命老区，金寨县革命博物馆收藏了大量革命文物。讲解词中的战地女婴故事，是无数革命故事中的一个，折射出战争年代普通人的牺牲与坚守。

🌐 全球对比

世界各国都有通过博物馆和纪念地传承历史记忆的做法。以色列大屠杀纪念馆通过个人故事让历史可感；美国华盛顿大屠杀纪念馆收集幸存者证言；欧洲许多二战纪念馆注重个体叙事。中国革命博物馆同样重视从“宏大叙事”转向“个体记忆”，让参观者通过一个名字、一件文物感受历史。这种叙事方式的转变，反映了历史教育理念的进步。

💭 思辨启发

战地女婴的故事为什么能打动人？因为它把宏大的革命历史落到具体的人身上。可以思考：历史教育应该侧重事件和数字，还是人物和情感？红色文化如何吸引年轻人？如果让你为家乡的革命博物馆写一段讲解词，你会选择讲什么故事？传承历史不是背诵结论，而是理解那些选择背后的信念和情感。

“十五五”考古：从“小众专业”走向“大众共享”

中国教育新闻网 阅读原文 →
📚 知识拓展

考古学是通过发掘和分析古代遗存来研究人类历史的学科。“十五五”规划期间，考古工作强调从专业研究走向公众共享，包括考古遗址公园建设、公众考古活动、数字化展示等。公众考古让普通人有机会了解考古发现和文化遗产保护，增强文化自信。这一转变反映文化遗产保护理念的进步：遗产不仅属于学者，更属于公众。

📜 历史纵深

中国现代考古学始于1921年仰韶村遗址发掘，至今已百余年。从最初few人参与的小众学科，到如今三星堆、海昏侯等考古发现引发全民关注，考古的社会影响力显著提升。2016年国家文物局提出“考古中国”重大项目，推动考古成果转化。近年来考古类节目、文创产品走红，说明公众对历史文化有强烈需求。考古从“冷门”变“热”，是文化自信提升的体现。

🌐 全球对比

公众考古在各国都有实践：英国通过“考古节”让公众参与发掘；美国有“考古月”活动；日本注重遗址公园建设与社区参与。中国公众考古起步较晚但发展快，数字化技术（如VR复原、线上直播）提供了新途径。不同国家的公众考古各有特色，但共同目标是让文化遗产保护成为社会共识，让历史研究惠及大众。

💭 思辨启发

考古走向大众是好事，但也要思考：公众参与会不会影响考古的严谨性？娱乐化传播会不会消解历史的厚重感？如何平衡专业研究与公众普及？对于中学生来说，了解考古不仅是增长知识，更是学习如何与历史对话。也许下一次博物馆之行，你会带着不同的问题去看展品。

✍️ 写作素材

适用于“与历史对话”“文化传承”等主题作文。开头示例：以前觉得考古就是“挖土”，直到在博物馆看到修复师用细刷一点点清理陶片，我才明白，考古是让沉默的过去重新开口说话。当考古从学术论文走进展览、直播和文创，历史就不再是课本上的年表，而是我们可以触摸的温度。

📚 知识拓展

岳麓书院创建于北宋开宝九年（976年），是中国古代四大书院之一，也是目前唯一还在招收学生的古代书院。1903年，它改制为湖南高等学堂，后来发展为湖南大学。书院大门上的对联“惟楚有材，于斯为盛”道出了这里人才辈出的历史。如今，湖南大学将书院文化融入现代大学教育，强调“经世致用”——学习要能解决实际问题，而不是空谈。

💭 思辨启发

千年书院为什么能“活”到今天？因为它不是被供起来的古董，而是不断转型的教育机构。从科举备考到现代大学，它一直在回答“教育为了什么”。这让我们思考：传统和现代真的对立吗？或许，真正的传承不是复制过去，而是像岳麓书院那样，把古老精神翻译成每个时代需要的语言。

本期话题：AI时代，我们如何与机器共处
科技伦理专家

AI正从工具变为伙伴，但伦理边界必须清晰。乌镇峰会上展示的智慧斑马线、会飞的救生圈等应用，说明AI已深入公共安全领域。我们需要建立“人机协作”的伦理框架：AI决策必须可解释、可追责，尤其在医疗、司法等关键领域。中学生应从小培养算法素养，理解AI的局限，不盲目崇拜技术。同时，要警惕AI偏见，比如训练数据中的性别或种族歧视。科技向善不是口号，而是需要制度保障和公众参与的过程。

教育技术学者

AI为教育带来个性化可能，但也可能加剧数字鸿沟。乌镇峰会展示的AI教育应用，能根据学生水平推送练习，但偏远地区网络和设备不足，反而拉大差距。教育者应把AI当作“助教”，而非“替代者”。比如，AI批改作文可以解放教师时间，但情感交流和价值观引导仍需真人。中学生要主动学习AI工具，同时保持批判思维——AI生成的内容未必正确，要学会验证。未来，懂AI就像今天懂上网一样，是基本素养。

社会学者

AI正在重塑劳动市场，青年一代面临机遇与挑战。进博会和乌镇峰会都显示，AI将替代重复性工作，但创造新的职业，如AI训练师、数据标注员。中学生选科和职业规划时，不必恐慌，而应关注不可替代的能力：创造力、共情力、复杂问题解决能力。同时，AI带来的“信息茧房”和“深度伪造”问题，考验社会信任机制。我们需要开展全民数字素养教育，让每个人都能负责任地使用AI，而不是被算法操控。

本期话题：AI进校园：利器还是隐患？
观点 A AI进校园是教育现代化的必然选择。它能提供个性化学习路径，比如智能辅导系统根据学生薄弱点推送练习，提高效率；教师可用AI批改作业、分析学情，腾出时间关注学生情感需求。乌镇峰会展示的智慧课堂已证明技术能激发兴趣。此外，AI素养是未来公民必备能力，早接触早受益。只要制定使用规范，防止抄袭和过度依赖，AI就能成为教育的得力助手。
观点 B AI进校园可能带来深层隐患。首先，过度依赖AI会削弱学生独立思考能力，比如用AI写作文、解数学题，导致思维惰性。其次，AI算法不透明，可能隐含偏见，影响教育公平。再者，学生数据隐私如何保护？校园AI系统收集大量行为数据，一旦泄露后果严重。更关键的是，教育不仅是知识传递，更是人与人之间的情感交流，AI无法替代教师的言传身教。在伦理框架不完善时，盲目推广AI风险太大。
🤔 AI 的立场 双方都有合理前提。A方成立的前提是：AI作为辅助工具，有明确使用边界和教师引导，且学校具备相应技术条件。B方成立的前提是：AI使用缺乏监管，学生自制力不足，数据保护不到位。实际上，AI进校园不是“要不要”，而是“怎么用”。需要制定分年龄、分学科的使用指南，加强师生AI伦理培训，并建立数据安全屏障。技术本身无善恶，关键在制度设计和人的选择。中学生应学会与AI协作，而非被其控制。
