纪念中国工农红军长征胜利90周年大会在京隆重举行 习近平发表重要讲话

📚 知识拓展

长征胜利90周年是2026年的重要纪念节点。1936年10月，红军三大主力在甘肃会宁会师，标志着长征胜利结束。长征历时两年，红军翻越18座大山，跨过24条大河，行程约二万五千里。纪念大会不仅回顾历史，更强调长征精神在新时代的传承。习近平总书记的讲话通常会对长征精神进行当代诠释，如坚定理想信念、艰苦奋斗、团结协作等，这些内容与中学生树立价值观密切相关。

📜 历史纵深

长征始于1934年10月，中央红军从江西瑞金出发，历经湘江战役、遵义会议、四渡赤水、飞夺泸定桥、爬雪山过草地等重大事件，最终于1936年10月胜利会师。遵义会议确立了毛泽东在党中央的领导地位，是生死攸关的转折点。长征保存了革命火种，为中国革命走向胜利奠定基础。90年来，长征精神一直是激励中国人民克服困难的精神动力。

🌐 全球对比

世界上许多国家都有类似“长征”的远征叙事，如以色列出埃及、美国西进运动，但长征独特的政治意义和艰苦程度罕见。国际学者常将长征与汉尼拔翻越阿尔卑斯山相比，但长征的群众基础和意识形态色彩更浓。近年来，长征历史吸引了不少外国记者和学者重走，如索尔兹伯里《长征——前所未闻的故事》。中国将长征精神作为国家记忆，与各国纪念建国战争有相似之处，但更强调政党与人民的结合。

💭 思辨启发

纪念长征胜利，是铭记历史还是面向未来？一方面，重温苦难辉煌能增强民族凝聚力；另一方面，过度强调苦难可能忽视时代变化。我们可以思考：长征精神中的“艰苦奋斗”在今天是否应转化为创新与担当？作为中学生，如何将“不怕困难”落实到学习生活中？此外，长征的胜利离不开人民群众支持，这启示我们任何事业都要依靠人民。不同国家对历史事件的纪念方式不同，我们应如何看待纪念活动的现实意义？

习近平对西藏那曲市巴青县7.0级地震作出重要指示

未来网 阅读原文 →
📚 知识拓展

巴青县位于西藏那曲市，地处青藏高原，平均海拔4500米以上，地震多发。7.0级地震属于强震，可能造成房屋倒塌、山体滑坡等次生灾害。习近平总书记的重要指示通常包括全力救援、妥善安置、防范次生灾害、加强监测预警等。高原地震救援面临高寒缺氧、交通不便等困难，国家会启动应急响应，调派救援力量。这体现了中国灾害应急管理体系“人民至上、生命至上”的原则。

📜 历史纵深

中国地震灾害频发，2008年汶川8.0级地震、2010年玉树7.1级地震、2013年芦山7.0级地震等都造成重大损失。每次灾后，国家都会总结经验，完善应急体系。2018年应急管理部成立，整合多部门力量，提升灾害应对能力。西藏地区地震活动频繁，1950年察隅8.6级地震是有记录以来中国最大地震之一。近年来，西藏基础设施改善，抗震设防能力提高，但高海拔地区救援仍面临挑战。

🌐 全球对比

日本、美国等地震多发国家有成熟的灾害应对体系。日本注重地震预警和建筑抗震标准，美国有联邦应急管理署（FEMA）协调救援。中国在灾害救援中强调集中力量办大事，动员军队、消防、医疗等多方力量。与发达国家相比，中国在偏远地区救援能力仍有提升空间，但近年来无人机、卫星通信等技术应用缩小了差距。全球地震救援合作也日益密切，如国际救援队互援。

💭 思辨启发

面对自然灾害，人类既脆弱又坚强。地震无法避免，但可以通过科学设防减轻损失。我们应思考：为什么高原地震救援更难？除了政府救援，普通人能做什么？比如学习防震知识、参与应急演练、不信谣不传谣。此外，灾后重建不仅是修房子，还要关注心理援助和生计恢复。从全球看，贫困地区往往受灾更重，如何通过发展增强韧性？这需要国家投入和国际合作。

北方出现大风降温天气 多地提前供暖

未来网 阅读原文 →
📚 知识拓展

提前供暖是民生保障的重要举措。中国北方供暖期通常为11月15日至次年3月15日，但遇强冷空气可提前。供暖涉及能源供应、管网运行、环境保护等多方面。近年来，多地推行“看天供暖”，根据气温变化灵活调整，体现精细化管理和以人为本。提前供暖也会增加能源消耗和排放，因此需要平衡民生与环保。清洁取暖改造（煤改气、煤改电）也在推进，以减少污染。

📜 历史纵深

中国集中供暖制度始于20世纪50年代，受苏联影响，以秦岭—淮河为界划分供暖区。早期供暖以燃煤为主，造成冬季大气污染。2013年“大气十条”实施后，北方推进清洁取暖，京津冀等地煤改气、煤改电。2017年，多部委印发《北方地区冬季清洁取暖规划（2017-2021年）》。近年来，智慧供热技术应用，根据天气精准调节，既保暖又节能。提前供暖从应急措施逐渐制度化。

🌐 全球对比

集中供暖在俄罗斯、北欧、北美等地常见。俄罗斯供暖期长，能源以天然气为主；丹麦大力发展区域能源和可再生能源供暖；美国以家庭独立供暖为主。中国集中供暖规模世界最大，但能源结构偏煤，低碳转型压力大。与欧洲相比，中国供暖价格受政府补贴，居民负担较轻，但能效有待提高。全球变暖背景下，供暖需求可能变化，但极端寒潮仍频发，供暖安全不容忽视。

💭 思辨启发

提前供暖是“暖心”之举，但也带来成本增加和排放上升。我们应思考：如何既保障民生又保护环境？清洁取暖改造让蓝天更多，但成本谁承担？政府补贴、企业让利、居民付费如何平衡？作为中学生，我们可以从身边做起，节约能源，比如调低室内温度、减少浪费。此外，气候变化导致极端天气增多，供暖制度是否需要更灵活？这考验城市治理的智慧。

有座火车站，名字就叫长征！

未来网 阅读原文 →
📚 知识拓展

长征站位于宁夏回族自治区中卫市海原县，是宝中铁路上的一个四等小站，因纪念红军长征而得名。宝中铁路连接陕西宝鸡和宁夏中卫，是西北地区重要通道。长征站虽小，却承载着红色记忆，成为当地红色文化地标。火车站命名通常依据地名，以“长征”命名全国罕见，体现了对历史的尊重。近年来，红色旅游兴起，长征站吸引游客打卡，带动地方发展。

📜 历史纵深

红军长征曾经过宁夏，1935年10月，中央红军翻越六盘山进入陕北。毛泽东写下《清平乐·六盘山》：“不到长城非好汉”。1936年10月，红二、红四方面军与红一方面军在甘肃会宁会师，长征胜利结束。宁夏是长征重要途经地，留下许多革命遗迹。宝中铁路1996年建成通车，长征站随之设立，站名沿用至今。它见证了中国铁路发展和西北变迁。

🌐 全球对比

以历史事件命名交通设施在国际上常见，如美国“自由之路”、法国“诺曼底大桥”。但以“长征”命名火车站独树一帜。其他国家也有红色旅游，如俄罗斯“红色旅游线”、越南“胡志明小道”。中国红色旅游规模大，将革命历史与旅游结合，促进老区发展。与一些国家去政治化不同，中国注重红色文化传承，长征站是微观案例。

💭 思辨启发

一个小站名，为何能引发关注？因为它连接历史与当下。名字是符号，提醒我们不忘来路。我们可以思考：红色地名如何保护利用？是仅仅保留名字，还是挖掘故事？长征站若只停留在打卡拍照，就失去了深度。如何让红色资源活起来？比如开发研学课程、设计文创产品。此外，小站客流少，如何平衡保护与开发？这需要智慧。

全球超八成新船订单涌向中国

中国青年网 阅读原文 →
📚 知识拓展

造船业是衡量一国工业实力的重要指标。中国造船业三大指标（造船完工量、新接订单量、手持订单量）连续多年居世界第一。全球超八成新船订单流向中国，说明中国在船舶设计、建造效率、成本控制等方面具有综合优势。绿色船舶、智能船舶是未来趋势，中国在液化天然气（LNG）船、大型集装箱船等高技术船舶领域取得突破。造船业带动钢铁、机械、电子等产业链发展。

📜 历史纵深

中国造船业曾长期落后，20世纪80年代开始承接国际订单，逐步学习技术。2000年后，中国造船业迅速崛起，2010年成为世界第一造船大国。但大而不强的问题曾存在，高技术船舶依赖进口。近年来，通过自主创新，中国在LNG船、超大型集装箱船等领域打破韩国垄断。2023年，中国新接订单量占全球67%，2026年超八成，显示绝对优势。造船业的逆袭是中国制造业升级的缩影。

🌐 全球对比

全球造船业长期由中日韩主导。韩国曾长期占据高端船舶市场，日本在效率和质量上有优势。近年来，中国凭借规模、成本和完整产业链赶超。欧洲在豪华邮轮、特种船舶领域仍领先。全球航运业绿色转型，国际海事组织（IMO）提出减排目标，推动船舶更新换代，中国抓住机遇，承接大量绿色船舶订单。造船业竞争也涉及地缘政治，美国试图重振造船业但面临挑战。

💭 思辨启发

八成订单流向中国，是喜是忧？喜的是中国制造竞争力强，忧的是过度集中可能引发贸易摩擦。我们应思考：中国造船业如何从“大”到“强”？核心技术和品牌价值仍需提升。此外，造船业周期性强，如何避免产能过剩？绿色船舶是方向，但技术门槛高，需要持续创新。作为中学生，我们可以关注中国制造如何向中国创造转变，培养工匠精神和创新意识。

警惕AI代写作业催生思维惰性

中国教育新闻网 阅读原文 →
📚 知识拓展

AI代写作业指学生使用生成式人工智能（如ChatGPT、文心一言等）完成作业。这类工具能快速生成作文、解题步骤甚至研究报告，但可能使学生跳过思考过程，导致思维惰性。教育界担忧，过度依赖AI会削弱学生批判性思维、问题解决能力和创造力。同时，AI生成内容可能存在错误或抄袭风险。如何合理使用AI辅助学习，成为教育新课题。

📜 历史纵深

本期话题：长征精神如何走进今天
党史研究专家

长征精神的核心是把全国人民和中华民族的根本利益看得高于一切，坚定革命的理想和信念，坚信正义事业必然胜利。90年过去，长征精神没有过时，因为它回答的是“为什么出发、为谁奋斗”的根本问题。今天的中学生了解长征，不能只背时间地点，而要理解红军在极端困境中的选择：面对围追堵截、雪山草地，他们靠什么坚持下来？靠的是对未来的信念和集体协作。学校开展“重走长征路”研学、讲长征文物故事，就是让历史从书本走进心里。走好新长征路，不是重复过去的路，而是带着那种精神解决今天的问题，比如攻克学习难关、参与科技创新、关心社会事务。

教育心理学专家

从青少年成长角度看，长征故事之所以有力量，是因为它提供了“逆境中坚持”的榜样。青春期学生常面临学业压力、人际困惑，容易产生无力感。长征中红军面对数倍于己的敌人和恶劣自然条件，依然保持乐观和纪律，这种叙事能激发心理韧性。但要注意，不能把长征精神简单化为“吃苦教育”，否则容易让学生产生距离感。有效的做法是把长征精神转化为日常可操作的目标：比如设定一个需要坚持的小目标，体验“坚持—克服—成功”的循环。学校和家庭应多提供“有挑战但可完成”的任务，让学生在真实体验中理解坚持的意义，而不是空洞说教。

中学历史教师

在中学历史教学中，长征是八年级上册第五单元“从国共合作到国共对立”的重要内容。学生需要掌握长征的原因、路线、遵义会议的意义和长征精神。但教材篇幅有限，我常补充细节：比如红军过草地时用皮带充饥，比如“半条被子”的故事。这些细节让历史有温度。本周新闻中“12件长征文物背后的烽火往事”就是很好的素材，可以让学生选一件文物写解说词，既练写作又加深理解。另外，长征路线涉及地理知识，可以跨学科结合：让学生在地图上标出翻越的山脉、渡过的河流，理解自然条件对行军的影响。历史不是死记硬背，而是通过具体的人和事，培养同理心和判断力。

⚔️ 观点碰撞

本期话题：AI代写作业该不该全面禁止
观点 A 应该全面禁止。AI代写作业会让学生跳过思考过程，直接获得答案，长期下去导致思维惰性、能力退化。作业的目的是巩固知识、训练思维，如果交给AI，就失去了意义。而且AI生成的内容不一定准确，学生不加辨别地抄写，反而可能学到错误知识。学校应明确禁止AI代写，并加强过程性评价，比如课堂讨论、口头汇报，让学生的真实水平显现出来。家长也要配合监督，不能只看结果不看过程。
观点 B 不应全面禁止，而应引导合理使用。AI是工具，就像计算器、搜索引擎一样，关键看怎么用。禁止只会让学生偷偷用，不如教会他们如何用AI辅助学习：比如用AI检查思路、拓展资料、修改语法，而不是直接抄答案。未来社会需要人机协作能力，学生早接触、早学会辨别AI输出的优劣，反而有益。学校可以设计“AI辅助作业”，要求学生标注哪些部分用了AI、如何修改，培养诚信意识和批判思维。一刀切禁止，可能扼杀学习兴趣。
🤔 AI 的立场 双方都有成立的前提。A方成立的前提是：作业的核心目标是训练独立思维，且学生自控力不足、AI输出质量参差，全面禁止能守住底线。B方成立的前提是：AI已不可回避，教育应培养辨别与协作能力，且学校有能力设计过程性评价、家长能有效监督。真正的问题不是“禁不禁”，而是“如何教学生负责任地使用AI”。在评价方式单一、学生缺乏引导的情况下，禁止是稳妥选择；在评价多元、引导到位的情况下，开放使用更有利于成长。所以，讨论应聚焦于改进作业设计与评价方式，而不是简单站队。

写作时先亮明观点，再用一个具体事例展开。事例要真实、有细节，比如“我参加长跑训练，跑到第三圈想放弃，但想到红军过雪山，我调整呼吸坚持跑完”。然后分析这个事例体现了长征精神的哪个方面（坚持、团结等）。最后可以提出一个行动建议，比如“在班级设立‘坚持打卡’小组”。注意避免堆砌形容词，用平实的语言讲清楚自己的思考。字数控制在300字左右，重点是把“大精神”和“小事情”连接起来。
