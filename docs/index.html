党的二十届五中全会审议通过《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》

未来网 阅读原文 →
📚 知识拓展

党的二十届五中全会是中国共产党在2026年召开的一次重要会议，全会审议通过了关于持之以恒推进全面从严治党的决定。全面从严治党是“四个全面”战略布局的重要组成部分，核心是加强党的领导，基础在全面，关键在严，要害在治。这次全会强调“持之以恒”，意味着反腐败斗争和作风建设不会放松，而是持续深入。

📜 历史纵深

中国共产党自成立以来就重视纪律建设。从延安时期的整风运动，到改革开放初期的整党，再到十八大以来的全面从严治党，反腐倡廉一脉相承。2012年中央八项规定出台，2018年国家监察委员会成立，制度笼子越扎越紧。

🌐 全球对比

许多国家都有反腐败机构，如新加坡贪污调查局、香港廉政公署。中国共产党以自我革命精神推进反腐败，力度大、成效显著，得到人民广泛支持。中国还积极参与全球反腐败治理，推动构建廉洁丝绸之路。

💭 思辨启发

全面从严治党为什么需要“持之以恒”？可以从权力监督的长期性、腐败问题的顽固性、民心所向等角度思考。也可以讨论：在校园生活中，如何理解“规则”和“自律”的重要性？

📚 知识拓展

四渡赤水是红军长征中的经典战例。1935年1月至3月，中央红军在毛泽东等指挥下，在贵州、四川、云南交界的赤水河畔四次渡河，灵活机动，摆脱了国民党军队的围追堵截。所谓“微操”是网络用语，指精细的指挥操作，这里形容红军高超的战术指挥艺术。

📜 历史纵深

遵义会议后，毛泽东重新获得军事指挥权。面对40万敌军，红军只有3万余人，毛泽东利用敌人矛盾，声东击西，四渡赤水，佯攻贵阳，威逼昆明，最终巧渡金沙江，跳出包围圈。这是长征中最惊心动魄的篇章之一。

🌐 全球对比

四渡赤水被许多军事院校列为经典战例，与汉尼拔翻越阿尔卑斯山、拿破仑奥斯特里茨战役等齐名。它体现了“以弱胜强”的军事辩证法，受到中外军事家的高度评价。

💭 思辨启发

以旧换新是鼓励消费者用旧产品折价换购新产品的政策，旨在促进消费、推动产业升级和绿色发展。2026年以来，该政策带动相关品类销售额超过2万亿元，涉及家电、汽车、电子产品等。这既刺激了内需，又有利于资源回收利用。

🌐 全球对比

国际金价跌破每盎司3900美元

中国青年网 阅读原文 →
📚 知识拓展

黄金是重要的避险资产，金价波动受全球经济形势、货币政策、地缘政治等多重因素影响。国际金价跌破每盎司3900美元，可能反映市场对经济前景的预期变化或美元走强。黄金以美元计价，美元升值通常压制金价。

📜 历史纵深

二战后建立布雷顿森林体系，黄金与美元挂钩，35美元兑换1盎司黄金。1971年美国宣布美元与黄金脱钩，金价自由浮动。2008年金融危机后金价大涨，2020年突破2000美元，近年波动加剧。

🌐 全球对比

各国央行黄金储备是金融安全的重要屏障。美国、德国黄金储备最多，中国也在增加黄金储备。金价波动对黄金生产国和消费国影响不同，印度和中国是黄金消费大国。

💭 思辨启发

金价下跌对普通人有什么影响？可能意味着避险情绪降温，经济预期改善，但也可能影响黄金投资者。可以讨论：投资黄金是稳赚不赔吗？如何理性看待投资风险？

2亿年前蝈蝈嗓门有多高？化石研究得出答案

新华网 阅读原文 →
📚 知识拓展

中国科学院南京地质古生物研究所的科研人员通过对全球1000多块螽斯化石的研究，重建了2.4亿年前螽斯的鸣声频率。螽斯是蝈蝈的学名，它们通过摩擦翅膀发声。这项研究有助于理解昆虫声学通讯的演化。

📜 历史纵深

古生物学通过化石研究远古生物。螽斯化石罕见保存发声器官，这项研究利用形态学推断功能，是古生物学与物理学的交叉。相关成果发表于《美国科学院院报》。

🌐 全球对比

古生物研究是国际竞争与合作的重要领域。中国在澄江生物群、热河生物群等化石研究中成果丰硕。国际合作使科学家能获取全球标本，推动学科发展。

本期话题：长征精神如何照亮今天
历史学者

长征是人类历史上的伟大奇迹。1934年至1936年，红军穿越11个省份，翻越18座大山，跨过24条大河，行程约二万五千里。长征精神的核心是把全国人民和中华民族的根本利益看得高于一切，坚定革命的理想和信念，坚信正义事业必然胜利。今天，我们不再需要翻雪山过草地，但长征精神依然有现实意义。它告诉我们，面对困难要有必胜的信念，面对挑战要团结协作，面对诱惑要坚守纪律。学习长征历史，不是简单背诵时间地点，而是理解那种在绝境中寻找希望、在逆境中坚持奋斗的精神力量。

教育专家

长征精神是青少年成长的精神钙片。现在的孩子生活条件优越，很少经历挫折，容易缺乏韧性和毅力。长征故事提供了最好的挫折教育素材：红军战士在缺衣少食的情况下坚持行军，在枪林弹雨中保持乐观，这种精神对今天的孩子有强烈的感染力。教育者要善于把长征精神转化为学生可感知、可实践的内容。比如组织红色研学，让学生走一段“微长征”；开展主题班会，讨论“我的长征路”；在学科教学中融入长征元素，让历史活起来。关键不是灌输，而是引导学生在体验中感悟，把长征精神内化为自己的精神品质。

心理学家

从心理学角度看，长征精神蕴含着强大的心理韧性。心理学研究表明，心理韧性包括目标感、乐观、自我效能、情绪调节等要素。长征中红军战士有明确的目标（北上抗日），有乐观的精神（革命理想高于天），有相互支持的团队，这些都是心理韧性的保护因子。青少年学习长征精神，可以从中汲取心理力量。当遇到考试失利、人际关系困扰时，想想红军战士面对的是生死考验，自己的困难就显得没那么可怕了。同时，长征精神也提醒我们，成长不是一帆风顺的，挫折是成长的必经之路，关键是如何面对。培养心理韧性，就是给自己穿上心理铠甲。

观点 A 短视频为青少年提供了丰富的学习资源和表达平台。许多知识类短视频用生动有趣的方式讲解科学、历史、文化知识，降低了学习门槛，激发了学习兴趣。短视频也为青少年提供了展示才华的舞台，不少青少年通过短视频记录生活、分享创意，获得认同感和成就感。此外，短视频传播速度快、覆盖面广，有助于青少年了解社会动态、拓宽视野。只要合理使用，短视频可以成为青少年成长的有益工具。
